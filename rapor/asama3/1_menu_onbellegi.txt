# 1) Önbellek boş
$ docker compose exec redis redis-cli KEYS menu:*


# 2) Aynı menü iki kez istenir: GET /api/menu?yemekhane_id=1&tarih=2026-11-15&ogun_id=2
$ docker compose logs uygulama | grep ÖNBELLEK
[ÖNBELLEK] menu:1:2026-11-15:2 -> veritabanından geldi
[ÖNBELLEK] menu:1:2026-11-15:2 -> Redis'ten geldi

menu:1:2026-11-15:2

111381
